# Index

One line per note. A line is a **trigger**: the words or questions that should
send an agent to the note, not a summary of it. Search and prompt suggestions
read these lines, so their quality decides whether a note is found.

Format: `- [[folder/Note]] — TRIGGER WORDS / questions: what is inside`
Put `READ FIRST` in a line to have it shown at every session start (keep at
most four such lines).
